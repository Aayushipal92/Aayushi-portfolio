# Portfolio Website

A modern, animated personal portfolio built with **React**, **Vite**, **CSS**, and **Framer Motion**.

## Features

- Smooth scroll navigation with sticky header
- Framer Motion animations (hero stagger, scroll reveals, hover effects)
- Glassmorphism UI with gradient accents
- Responsive layout for mobile and desktop
- Sections: Hero, About, Skills, Projects, Contact

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Customize

Edit `src/data/portfolio.js` to update your name, bio, skills, projects, and social links.

## Build for Production

```bash
npm run build
npm run preview
```
